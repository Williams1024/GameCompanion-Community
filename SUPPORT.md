# Support

## Public help

Use GitHub Issues for repeatable product bugs and GitHub Discussions for questions, setup advice, and community conversation. Feature requests are welcome from every Game Companion tier.

## Private help

Email [support@game-companion.com](mailto:support@game-companion.com) for account access, billing, referrals, licenses, private logs, or anything containing personal information.

This public repository does not contain the Game Companion application source and cannot accept source-code pull requests.
