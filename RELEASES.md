# Game Companion release notes

This is the public, source-free release history for Game Companion.

Each public application release will receive a concise entry describing visible improvements, important fixes, upgrade notes, and known limitations. Signed installers remain distributed through the official Game Companion update channels and website.

## Current public release

The in-app updater is the authoritative source for the currently promoted version. Version-specific public notes will be added here as the release-note publishing workflow is connected to this repository.
