# Game Companion Community

Welcome to the public home for Game Companion release notes, bug reports, feature requests, questions, and ideas.

**Community** is Game Companion's free entry tier, but this space is for everyone using Game Companion—Community, trial, Explorer, Crafter, Architect, and future plans.

## Start here

- Found a repeatable problem? [Open a bug report](../../issues/new?template=bug_report.yml).
- Have an idea? [Open a feature request](../../issues/new?template=feature_request.yml).
- Need help or want to compare setups? Start or join a GitHub Discussion.
- Need private account or billing help? Email [support@game-companion.com](mailto:support@game-companion.com).

## Release notes

Public release notes will appear in [Releases](../../releases) and in [RELEASES.md](RELEASES.md). The application source, signing system, operational tooling, and customer data remain in private systems.

## Before posting

Please remove email addresses, API keys, tokens, account IDs, payment details, and other personal information from screenshots and logs. Security vulnerabilities should not be filed publicly; follow [SECURITY.md](SECURITY.md).
