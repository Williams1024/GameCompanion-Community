# Contributing

Thank you for helping improve Game Companion.

- Search existing Issues and Discussions before opening a new item.
- Use the provided form and include the Game Companion version and account tier.
- Provide the smallest repeatable set of steps and the expected versus actual result.
- Remove secrets and personal information from logs and screenshots.
- Keep one problem or request per Issue.
- Use Discussions for open-ended questions, ideas, and setup comparisons.

This repository is a public support and release-information hub. The application source is private, so source-code pull requests are not accepted here.
